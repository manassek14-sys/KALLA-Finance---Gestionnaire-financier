KALLA FINANCE — VERSION PERSONNALISABLE
======================================

Fichiers de cette version :
- index.html : application principale
- styles.css : apparence et couleurs
- app.js : calculs et fonctionnement
- dashboard.html : raccourci vers le tableau de bord
- gestion.html : raccourci vers la gestion financière

Installation depuis un iPhone :
1. Ouvrir le dépôt GitHub.
2. Télécharger une copie des fichiers actuels ou vérifier l’historique avant tout remplacement.
3. Ajouter les nouveaux fichiers styles.css, app.js, dashboard.html et gestion.html à la racine.
4. Remplacer index.html par celui de cette archive seulement après sauvegarde de l’ancien fichier.
5. Enregistrer chaque modification avec Commit changes.
6. Dans Settings > Pages, garder main et /(root).
7. Attendre le déploiement, puis ouvrir l’adresse du site.

Ne remplace pas manifest.webmanifest, sw.js ou icon-192.png avec des fichiers provenant d’ailleurs. Garde ceux déjà présents dans ton dépôt.
Si l’ancien service worker affiche une ancienne version, ouvre le site dans Safari et recharge la page ; si besoin, supprime l’ancien raccourci PWA puis réouvre le site.

Données et confidentialité :
- Application monoposte : données stockées localement dans le navigateur.
- Les données ne se synchronisent pas automatiquement entre appareils.
- Utilise Personnalisation > Sauvegarde pour exporter un JSON.
- Exporte régulièrement les données ; la suppression des données du navigateur peut les effacer.
- Cette version n'est pas un système bancaire, une comptabilité certifiée ou un coffre-fort chiffré.

Calculs :
- Les revenus et dépenses sont des opérations saisies par l’utilisateur.
- Le bénéfice distribuable est un montant de référence saisi dans Personnalisation ; il n'est pas calculé automatiquement à partir des revenus moins dépenses.
- Les salaires/prestataires et autres charges doivent être enregistrés avant de déterminer le bénéfice réellement distribuable.
- Les pourcentages de chaque groupe doivent être ajustés pour totaliser 100 %.
